# Casa Nova

Шесть адаптивных страниц на HTML, CSS и JavaScript: пять основных и отдельная политика конфиденциальности. Логотип пересоздан в высоком разрешении с подписью снизу и прозрачным фоном. Хедер оформлен плавающей панелью; на сайте доступны Telegram с официальной иконкой и звонок. В портфолио два предоставленных проекта: раздевалка спортивной команды (7 фото) и монтаж инженерных систем в частной резиденции (34 фото). Иллюстрации команды и базы различаются. Все фотографии оптимизированы в WebP. Сторонние JavaScript-библиотеки, рекламные и аналитические системы не используются.

## Предпросмотр

Нужен Node.js 22 или новее. Установка пакетов не требуется.

```powershell
npm run dev
```

Откройте адрес, который выведет сервер. Если порт 4173 занят:

```powershell
$env:PORT = '4189'
npm run dev
```

Для проверки нужен HTTP-сервер: открытие index.html через file:// не поддерживает чистые URL и ES modules.

## Структура

- `dist/` — готовая статическая версия для хостинга, включая шесть HTML-страниц, изображения, шрифты и SEO-файлы.
- `scripts/views.mjs` — содержание и общие компоненты всех страниц.
- `scripts/build.mjs` — генерация HTML, метаданных, sitemap.xml и robots.txt.
- `assets/css/theme.css` — цвета, шрифты и основные размеры.
- `assets/css/styles.css` — адаптивная вёрстка, анимации и состояния.
- `assets/css/layout.css` — отдельные колонки первого экрана, отступы и оформление галерей.
- `assets/css/brand.css` — новый хедер, контакты, согласие, прелоудер, cookie-плашка и политика.
- `assets/js/experience.js` — короткий прелоудер, технические настройки и анимации.
- `scripts/approach.mjs`, `assets/css/approach.css`, `assets/js/approach.js` — интерактивные этапы работы на странице компании и ссылка на них с главной. Переключение кнопками и клавиатурой, ожидание загрузки фото, фиксированная высота сцены и reduced motion.
- `content/company.json` — подтверждённые сведения из карточки предприятия.
- `scripts/legal.mjs` — содержание политики и отдельного текста согласия.
- `content/projects.mjs` — два реальных проекта и все 41 фото.
- `assets/js/app.js` — меню, форма и маска. Всплывающие окна контента убраны.
- `assets/js/gallery.js` — галереи на странице проектов: стрелки, миниатюры, клавиатура и свайпы.
- `assets/js/form-utils.js` — логика редактирования телефона и проверки формы.
- `site.config.json` — телефон, ссылки мессенджеров, домен и адрес отправки формы.
- `tests/phone.test.mjs` — девять тестов формы и маски.
- `scripts/browser-qa.mjs` — браузерные проверки маршрутов и взаимодействий.

Редактируйте исходники, затем запускайте `npm run build`. Содержимое `dist/` генерируется заново.

## Домен и SEO

Пока `domain` пустой, все страницы имеют `noindex,nofollow`, а robots.txt запрещает индексацию. Canonical, Open Graph, JSON-LD и sitemap используют демонстрационный адрес из `previewOrigin`.

После выбора основного домена укажите HTTPS origin без пути в `site.config.json`, например значение реального домена в поле `domain`, и выполните `npm run build`. Сборка обновит все абсолютные URL, sitemap, robots и включит индексацию. Перед публикацией проверьте HTTPS и перенаправление второстепенных вариантов домена на основной. Загружайте **содержимое dist/** в корень сайта.

Включены: уникальные title и description, один h1 на страницу, семантическая разметка, alt, хлебные крошки внутренних страниц, Organization и BreadcrumbList JSON-LD, Open Graph, favicon, локальные шрифты, предзагрузка главных шрифтов, приоритет главной фотографии и отложенная загрузка остальных изображений. `404.html` должен отдаваться хостингом с HTTP 404; не включайте SPA fallback на index.html.

## Почта и форма

Почта для заявок на основном домене и серверная отправка ещё не подключены. `formEndpoint` пустой: после успешной проверки полей посетитель получает честное сообщение и может использовать Telegram или телефон. Сайт **не сообщает об успешной отправке**, если отправки не было. Имя и телефон не сохраняются в localStorage и не отправляются аналитике.

Для подключения почты понадобится серверный обработчик или почтовый сервис. Укажите его HTTPS URL либо путь того же сайта в `formEndpoint`. Фронтенд отправляет POST JSON:

```json
{"name":"Анна","phone":"+79919239912","consent":true}
```

Успех принимается только при HTTP 2xx и JSON `{"success":true}`. Остальные ответы, отсутствие сети и таймаут 15 секунд показывают сообщение об ошибке и альтернативные контакты. Кнопка блокируется на время отправки. SMTP-ключи храните только на сервере; в клиентскую конфигурацию они не добавляются. Серверный обработчик должен проверять поля, ограничивать частоту запросов и доставлять письмо на реальную почту. Сам обработчик не входит в эту статическую версию, поскольку хостинг и почта ещё не выбраны.

## Мессенджеры

WhatsApp полностью удалён из интерфейса, метаданных и клиентской конфигурации. Telegram использует ссылку по номеру; она зависит от настроек обнаружения номера в аккаунте. При наличии username замените поле `telegram` на постоянную ссылку аккаунта. Иконка взята из [официального набора Telegram](https://telegram.org/tour/screenshots) и сохранена локально в assets/icons/telegram.svg. Номер открывает приложение звонков через tel:.

## Cookie и прелоудер

Cookie-плашка сообщает только о техническом хранилище. Подтверждение хранится в localStorage в `cn-cookie-choice:v1` до 12 месяцев; открыть уведомление повторно можно из подвала. Рекламные и аналитические cookie не добавлены.

Быстрый прелоудер показывается только на главной при каждом открытии и обновлении — около 0,42 секунды в проверке. На внутренних страницах, при переходе к ним и их восстановлении из кеша заставка не появляется. Якоря внутри главной также не запускают её. Отметка посещения больше не хранится. Параметры — в начале assets/css/brand.css: удержание 180 ms, уход 240 ms, ожидание ресурсов до 400 ms. Escape пропускает заставку, prefers-reduced-motion отключает её. Независимый таймаут в HTML открывает главную через 1,2 секунды даже при отказе основного JavaScript.

## Контент для финального запуска

- Основной домен.
- Почтовый адрес и серверный обработчик отправки.
- Подтверждение доступности номера в Telegram либо Telegram username.
- Дополнительные факты о проектах можно добавить позднее: адреса, площади и сроки не выдуманы.
- Согласование и актуализация политики перед реальным приёмом заявок.

## Проверка

```powershell
npm run verify
```

Команда запускает 22 теста, сборку и 490 статических проверок страниц, ссылок, ресурсов, метаданных и JSON-LD. Браузерная проверка охватывает все шесть страниц на 1920, 1440, 1280, 1024, 853, 768, 760, 360 и 320 px, а также меню, форму, маску, все 41 фото, cookie и прелоудер. В `scripts/experience-qa.mjs` проверяются запрет и повреждение хранилища, повторное открытие и возврат фокуса, reduced motion, Escape и отказ основного модуля. `scripts/approach-qa.mjs` проверяет четыре этапа на шести ширинах: границы текста, заполнение фоторамки, отсутствие наложений и скачков высоты, клавиатуру, быстрые переключения, reduced motion и медленную загрузку фотографии. Результаты в `docs/verification.md`.
