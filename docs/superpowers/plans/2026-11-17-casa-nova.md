# Casa Nova Implementation Plan

**Goal:** перенести утверждённый референс в адаптивный сайт из пяти страниц.

**Architecture:** buildless HTML/CSS/JS в выдаче; небольшой Node.js генератор создаёт общий header/footer, метаданные и dist. Без сторонних runtime-зависимостей.

**Tech Stack:** HTML5, CSS custom properties, ES modules, Node.js built-ins.

## Global Constraints

Все тексты главной из референса. Все фотографии заново сгенерированы. Телефон 8 (991) 923-99-12. Почту и домен не придумывать. Пять страниц. Работать в текущей пустой папке без Git.
