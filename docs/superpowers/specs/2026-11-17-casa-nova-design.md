# Casa Nova — утверждённый дизайн

Основание: пользователь утвердил приложенный референс и прямо поручил перенести его в HTML, CSS и JavaScript. Повторное согласование дизайна не требуется.

Пять страниц: /, /about/, /projects/, /services/, /contacts/. Главная сохраняет все тексты и последовательность блоков референса. Внутренние страницы продолжают тот же дизайн и раскрывают только подтверждённые сведения, без вымышленных кейсов, отзывов, цен и реквизитов.

Палитра: тёплый молочный фон, тёмно-коричневый текст, приглушённое золото. Контрастная антиква для заголовков, нейтральный гротеск для текста. Асимметричная обложка, скруглённые фото, арочные материалы, разрез конструкции с интерактивными указателями.

Изображения генерируются заново по референсу. Логотип предоставлен пользователем. Изображения интерьеров — визуализации, а не утверждение о выполненных проектах. Благодарственное письмо — декоративный образец без выдуманного отзыва.

Телефон: 8 (991) 923-99-12. Чат открывает выбор WhatsApp и Telegram. Telegram пока по номеру телефона; username можно заменить в настройках. Почта и домен ещё не созданы. Форма валидируется, корректно редактирует маску, не сообщает об отправке без реального endpoint.

Адаптация: 1440/1280, 768, 360, 320 px. Меню с плавным раскрытием, без сдвига контента, блокировкой прокрутки и сохранением позиции; Escape и управление фокусом. Лёгкие анимации с prefers-reduced-motion.

SEO: статический HTML, уникальные title/description/h1, Open Graph, JSON-LD только подтверждённых сведений, хлебные крошки, sitemap и robots через конфигурацию домена. Демонстрационная версия закрыта от индексации.
