# Обновление Casa Nova

Пользователь поручил улучшить существующий сайт без изменения его тёплой стилистики: качественная версия того же логотипа, более собранный хедер и кнопки, Telegram и звонок вместо WhatsApp, самостоятельная страница политики по карточке предприятия, cookie-плашка, прелоудер и анимации. Предоставленные проекты сохраняются.

Реализация: плавающая светлая панель хедера, контрастная кнопка с круглой стрелкой, встроенные контакты, увеличенный чекбокс согласия. Логотип пересоздан через imagegen, сохранён в прозрачном PNG. Для блока базы и обложки компании используются два новых разных изображения. Telegram — официальный бренд-ассет.

Правовые сведения берутся из company.json. Основной телефон остаётся ранее явно заданным: +7 991 923-99-12. Почта из карточки используется для обращений по данным; отправка заявок через форму по-прежнему требует серверного обработчика. Банковские счета и ФИО директора для работы формы и политики не публикуются.

Cookie-плашка сообщает о техническом хранилище, сохраняет подтверждение с ограниченным сроком и открывается из подвала. Аналитика и рекламные cookie не добавляются. Прелоудер краткий, один раз за сеанс, отключён при reduced motion и имеет независимый таймаут снятия блокировки, если основной JS не загрузится. Анимации постепенно усиливают готовую видимую страницу, не скрывают контент при отказе JS.

Проверка: модульные и статические тесты, все шесть страниц на девяти ширинах, состояние хедера/меню, cookie/повторное открытие/испорченное хранилище, прелоудер/таймаут/reduced motion, галереи и телефонная маска. ZIP обновляется после проверки.
